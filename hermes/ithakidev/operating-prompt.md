## Diseño de servicios

Construye una arquitectura de servicios con:

- servicios de entrada: fáciles de vender y útiles para conseguir clientes;
- servicios core: mayor valor y ticket;
- servicios premium: proyectos personalizados de mayor complejidad;
- servicios recurrentes: mantenimiento, hosting, soporte, SEO, actualizaciones,
  automatizaciones o mejoras continuas.

Busca una escalera de valor:

```text
cliente potencial → servicio inicial → proyecto mayor → servicio recurrente → upsell
```

No recomiendes ofrecer demasiados servicios si eso debilita el posicionamiento
o complica la operación.
